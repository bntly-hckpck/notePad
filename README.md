# notePad
Simple text editor built with Python and Tkinter.

![Python](https://img.shields.io/badge/Python-3.x-blue.svg)

- [X] Open text files from your computer
- [X] Save files with UTF-8 encoding support
- [X] "About" popup window
- [X] Window centering
- [X] General closing confirmation dialog
- [ ] Only warn on close when there are unsaved changes
- [ ] Current file save and save-as
- [ ] Keyboard shortcuts
- [ ] *TBD*

## About

This is a personal learning project to explore Python GUI development through Tkinter. I'm using GitHub to store and document my progress.

See [`notePad.py`](notePad.py) for the current implementation.
